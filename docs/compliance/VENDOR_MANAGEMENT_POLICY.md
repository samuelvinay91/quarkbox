# Vendor Management Policy

## 1. Purpose & Scope
This policy establishes a standardized framework for assessing, managing, and mitigating risks associated with third-party vendors and service providers utilized by QuarkBox.

## 2. Third-Party Risk Assessment Framework
Prior to engagement, all prospective vendors must undergo a rigorous risk assessment to evaluate their security posture, data handling practices, and alignment with QuarkBox requirements.

## 3. Vendor Onboarding Security Review
Vendor onboarding requires successful completion of a security review, which includes:
- Verification of current SOC2 Type II or ISO 27001 certifications.
- Review of data residency capabilities and compliance with applicable data protection regulations.
- Execution of requisite Non-Disclosure Agreements (NDAs) and Data Processing Agreements (DPAs).

## 4. Critical Vendor Inventory
QuarkBox maintains an up-to-date inventory of all critical vendors. Categories include, but are not limited to:
- Cloud Service Providers (e.g., AWS, GCP).
- Managed Database Services.
- Identity and Authentication Providers.
- Telemetry and Monitoring Solutions.

## 5. Annual Vendor Security Re-assessment
- All critical vendors are subject to an annual security re-assessment to verify continuous compliance with QuarkBox's security standards.
- Offboarding criteria are established to securely terminate vendor relationships, ensuring the secure return or destruction of QuarkBox data and the revocation of any granted access.
